PORTOFOLIO AMISAH - CARA EDIT DAN DEPLOY

File:
- index.html  : isi dan teks halaman (nama, About, Experience, Education, Contact)
- style.css   : warna dan tampilan (warna ada di bagian :root paling atas)
- script.js   : data kartu skill dan isi 4 proyek demo (daftar crit, w, t3, r4)
- CV_Amisah_Indonesian_Bilingual_Expert.pdf : file untuk tombol Download CV

Edit:
1. Buka file dengan editor teks (VS Code atau Notepad).
2. Ganti link GitHub di index.html (cari: https://github.com/).
3. Buka index.html di browser untuk melihat hasilnya.

Deploy:
- Netlify: buka app.netlify.com/drop, lalu seret seluruh folder ini.
- Vercel: upload folder ini sebagai project static (tanpa build command).
Pastikan file PDF CV tetap berada di folder yang sama dengan index.html.
